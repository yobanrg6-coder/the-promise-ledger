Zero-LLM verifier — point-in-time

Probe 1: the official page as archived by the Wayback Machine on/before the deadline — keywords in that capture = kept on time, the capture date is the dated proof. Probe 2: the page now. A fixed table turns the two readings into one status; every verdict records how it was reached. “It shipped” is never an inferred claim.

ledger/verifier.py  ·  ledger/archive.py  ·  ledger/evidence.py
 
Seven fixed statuses — decision table in ledger/README.md
PENDING FULFILLED FULFILLED_LATE PARTIALLY_FULFILLED DELAYED ABANDONED UNVERIFIABLE

Seeded demo: 8 real promises / 6 companies (Meta, Anthropic, Apple, xAI, Stability AI, OpenAI). 4 verify point-in-time against the company's own official page via the archive (incl. OpenAI's bot-blocked download page). Outcomes kept visible: 1 ABANDONED, 1 FULFILLED_LATE, 1 undated FULFILLED. Seed on-time rate 71.4%.

Deployment: Google Cloud Run (source deploy) · Gemini key in Secret Manager · fully offline test suite (no network, no LLM)
Model discipline: gemini-3.5-flash-lite (extractor) + gemma-4-26b-a4b-it (auditor) — pinned, no -latest alias
